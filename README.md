# Python practice programs

A collection of small Python learning exercises covering control flow, functions, recursion, dictionaries, sets, tuples, strings and exception handling.

## Getting started

Use Python 3 in an isolated environment. Read each script before running it; some exercises request interactive input. For example, `python calculator.py` runs the calculator exercise. Notebook files can be inspected using Jupyter.

## Scope

These are learning examples rather than a packaged application. Dependencies and behavior may vary by exercise. No automated test coverage or production readiness is claimed.
